# 90-约束与检查清单

<!-- description: DQT-96 不可触碰的红线与代码变更后必过验证清单。任何修改计分相关代码前后必读。 -->

## 关键约束与红线

| 约束 | 说明 |
|---|---|
| ❌ 不得修改 diffCoeff 系数 | 会影响所有已出题目的权重，需同步更新 maxPts 计算 |
| ❌ 不得修改已部署的题库编号 | 历史数据的题号与 Google Sheets 明细表关联 |
| ⚠️ 修改 pts 值需谨慎 | 会影响该题型所有题目的权重分布 |
| ⚠️ 修改 TOTAL_Q/MIN_PER_DIM | 会改变测试长度和维度覆盖，需同步更新进度条 |
| ✅ 可以改题干/选项表述 | 不影响计分，但需保证答案(ans)不变 |
| ✅ 可以新增/删除题目 | 但 dim/diff/pts 分布需保持平衡 |
| ✅ 可以改等级阈值 | 纯展示层面修改，不影响原始分数 |

## 代码变更检查清单

修改任何计分相关代码后，必须逐一验证：

### 选题
- [ ] 种子题生成是否正确（4题，各维度1道中等）
- [ ] pickNext 选题是否不重复、不超 MIN_PER_DIM

### 计分
- [ ] diffCoeff 是否正确应用
- [ ] 多选一票否决是否生效
- [ ] 多选部分正确是否给安慰分
- [ ] 回退修改：answered/maxPts 不变、totalPts 重算

### 结果
- [ ] 总分 = Σ(totalPts) / Σ(maxPts) × 100
- [ ] 各维度得分率 = totalPts/maxPts × 100
- [ ] 满分等级阈值：≥75 高 / ≥55 中 / <55 低
- [ ] 二维评级矩阵输出正确（百分比等级 × 满分等级交叉）
- [ ] 薄弱项提示阈值 = 60%

### 导出
- [ ] Google Sheets 上传字段与列对齐（含 K、L 列）
