### 新增字段说明（2026-05-18）

**L列 - 满分等级**：根据选题算法生成的满分高低，分为三档：
- 高难度组（满分 ≥ 75）
- 中难度组（满分 55–74）
- 低难度组（满分 < 55）

**M列 - 二维评级**：综合得分率和满分等级得出的最终评级：
- 卓越 / 优秀 / 良好 / 待提升⁺ / 待提升 / 待提升⁻ / 薄弱⁺ / 薄弱 / 薄弱⁻

## 传输机制

- `fetch()` POST 到 Google Apps Script Web URL
- `mode: 'no-cors'`, `Content-Type: text/plain`
- 测试完成后静默上传，不给用户提示
- 写入失败不影响页面正常使用

## 接收端

文件：`Code.gs`（Google Apps Script）

部署为 Web App 后接收 POST 请求，解析 JSON 写入对应的 Google Sheets（汇总表 + 明细表）。
