## 传输机制

- `fetch()` POST 到 Google Apps Script Web URL
- `mode: 'no-cors'`, `Content-Type: text/plain`
- 测试完成后静默上传，不给用户提示
- 写入失败不影响页面正常使用

## 接收端

文件：`Code.gs`（Google Apps Script）

部署为 Web App 后接收 POST 请求，解析 JSON 写入对应的 Google Sheets（汇总表 + 明细表）。
