## 一、难度系数

```javascript
function diffCoeff(d) {
  return d === 1 ? 1.0 : d === 2 ? 1.5 : 2.0;
}
```

| diff | 标签 | 系数 | 含义 |
|---|---|---|---|
| 1 | 简单 | ×1.0 | 基础识别能力 |
| 2 | 中等 | ×1.5 | 常规分析能力 |
| 3 | 困难 | ×2.0 | 高阶推理能力 |

**每题实际满分 = 基础分(pts) × 难度系数(diffCoeff)**

| 题型 | diff=1 | diff=2 | diff=3 |
|---|---|---|---|
| 单选 (pts=1) | 1 分 | 1.5 分 | 2 分 |
| 多选 (pts=2) | 2 分 | 3 分 | 4 分 |
| 判断 (pts=1) | 1 分 | 1.5 分 | 2 分 |

> 困难题权重是简单题的 2 倍，答对困难题体现更高的维度能力。

## 二、选题算法

### 常量

```javascript
const TOTAL_Q = 36;      // 每次测评总题数
const MIN_PER_DIM = 9;   // 每维度最少题数
```

### 种子题（前 4 题）

```
for each dim(1→4):
  pool = 该维度 diff=2 的题目
  题型软偏好抽取 1 题（pickBalanced），加入 selectedQ
```

目的：为每个维度建立一个中等难度的初始基线；同时通过题型偏好让 4 道种子题尽量覆盖不同题型。

### 动态选题（第 5 题起，`pickNext()`）

```
1. 找出 needs（未达 MIN_PER_DIM 的维度）
   - 有 needs → 选答题数最少 → 得分率最低 的维度
   - 无 needs → 选得分率最低的维度

2. 根据该维度当前得分率选择难度：
   得分率 ≥ 70%  → targetDiff = 3 (困难)
   得分率 ≥ 40%  → targetDiff = 2 (中等)
   得分率 < 40%  → targetDiff = 1 (简单)
   首次答题      → targetDiff = 2 (中等)

3. 从该维度对应难度且未做过的题中，用题型软偏好抽取（pickBalanced）
   该难度无可用题 → 降级到该维度任意未做题
   该维度无可用题 → 降级到任意未做题

4. 返回 null → 测试结束（实际不应出现，因为有 192 题备选 36 题）
```

#### pickBalanced 题型软偏好

```
pool 按「该维度已使用该题型的次数」升序排列
从前 3 名中随机抽取（既纠偏又保留一定随机性）
池小于 3 道时全部参与随机
```

目的：在保证自适应维度×难度主线不被打断的前提下，减少单题型连续出现的概率，降低题型偏向带来的运气成分。
```

### 设计意图

| 规则 | 目的 |
|---|---|
| 优先填满 MIN_PER_DIM | 保证每个维度有足量样本 |
| 得分率高→出难题 | 测试上限，避免天花板效应 |
| 得分率低→出简单题 | 确认基线，避免地板效应 |
| 同维度按得分率排优先级 | 弱项多测，强项挑战 |
| 不重复选题 | 避免学习效应 |
| 题型软偏好（pickBalanced） | 避免单题型扎堆，降低题型偏向带来的运气成分 |

## 三、单题计分

### 答案判定 `checkAnswer(q, ua)`

```javascript
- 单选: ua === q.ans
- 判断: ua === q.ans
- 多选: ua 长度 === q.ans 长度 && q.ans 每一项都在 ua 中
```

### 计分函数 `getScore(q, ua)`

```javascript
let c = diffCoeff(q.diff);

// 单选/判断
if (q.type === 'single' || q.type === 'judge')
  return checkAnswer(q, ua) ? q.pts * c : 0;

// 多选
if (q.type === 'multiple') {
  let uas = new Set(ua || []);
  let cas = new Set(q.ans);

  // 选了不在答案中的项 → 0 分（一票否决）
  if ([...uas].some(a => !cas.has(a))) return 0;

  // 全对 → 满分
  let overlap = [...uas].filter(a => cas.has(a)).length;
  if (overlap === cas.size) return q.pts * c;

  // 部分对 → 安慰分（1 × c）
  return 1 * c;
}
```

### 多选计分详解

| 场景 | 得分 |
|---|---|
| 全选对，不多选 | pts × c（满分） |
| 选对了部分但没选全，没多选 | 1 × c（安慰分） |
| 选了任何一个错误选项 | 0（一票否决） |
| 什么都没选 | 0 |

### 设计意图
- **一票否决**：防止蒙答案——选错一个说明理解有偏差
- **安慰分**：部分正确的理解也有价值，不全盘否定
- **难度加权**：同样的全对，困难题得分是简单题的 2 倍

## 四、分数累加

### dimState 数据结构

```javascript
dimState = {
  1: { answered: 0, totalPts: 0, maxPts: 0 },
  2: { answered: 0, totalPts: 0, maxPts: 0 },
  3: { answered: 0, totalPts: 0, maxPts: 0 },
  4: { answered: 0, totalPts: 0, maxPts: 0 },
}
```

| 字段 | 含义 | 首次答题 | 回退修改 |
|---|---|---|---|
| `answered` | 该维度已答题数 | +1 | **不变** |
| `totalPts` | 该维度累计得分 | +本题得分 | 扣旧分 + 加新分 |
| `maxPts` | 该维度累计可得分 | +q.pts × coeff | **不变** |

### 回退修改规则

```
if (userAnswers[currentIdx] 已有旧答案) {
  totalPts -= 旧答案得分;       // 扣旧
} else {
  answered++;                    // 仅首次+1
  maxPts += q.pts × coeff;      // 仅首次计入
}
totalPts += 新答案得分;          // 加新
```

### 设计意图
- `maxPts` 按首次选题时的难度算，不因回退而改变
- 防止利用"上一题"反复换题刷高分（新题难度固定，但 maxPts 已锁定）
- 但允许修正手滑误选（仅重算得分）
